# 双顶双底识别指标 — 规则文档

> Pine Script v5 | 文件: `pine/双顶双底识别.pine` | 2026-08-12

---

## 一、指标概述

在图表上识别双顶（M头）和双底（W底）形态。基于枢轴点 + ATR 自适应偏差 + 弹性搜索，颈线突破后标注。

## 二、参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 枢轴 Lookback | 6 (左6右6) | `ta.pivothigh` / `ta.pivotlow` 检测窗口 |
| ATR 周期 | 14 | 计算 ATR 的周期 |
| ATR 偏差倍数 | 2.0 | 两顶/底之间价格偏差容忍度 = atrMult × ATR |
| 弹性搜索窗口 | 5 | 保留最近 5 个同类型枢轴点进行配对搜索 |
| 严格模式 | 开启 | 中间回撤点必须是枢轴低点/高点 |
| 待确认超时 | 200 bar | 超过此 bar 数颈线未突破则放弃候选 |

## 三、形态识别规则

### 3.1 枢轴点源

使用 `ta.pivothigh(high, 6, 6)` 和 `ta.pivotlow(low, 6, 6)`。检测到的新枢轴推入队列，保留最近 5 个。

### 3.2 弹性搜索配对

每次检测到新枢轴高点时，遍历队列中所有更早的枢轴高点，尝试配对。

**配对条件**：

1. **价格偏差**：`|top1_price - top2_price| ≤ 2 × ATR`（ATR 取第二个顶形成时的值）

2. **中间枢轴可跳过条件**（弹性搜索核心）：
   - 若两枢轴之间有其他枢轴 k，k 必须同时满足以下条件才能被跳过：
     - **a) 价格距离**：k 与配对的两个枢轴的价格差距都 > 2×ATR
     - **b) 形态边界**：双顶中 k 不能高于两顶的最高值 / 双底中 k 不能低于两底的最低值
   - 若任何中间枢轴不满足上述条件 → 不可跳过 → 该对无效（应由 k 与最近的端点形成自己的配对）

3. **中间回撤**：
   - 严格模式：两顶之间的最低点必须是已记录的枢轴低点
   - 宽松模式：两顶之间的最低点即可（不要求是枢轴点）

### 3.3 颈线确认与失效

配对成功后进入待确认队列。从第二个顶/底形成开始，逐 bar 检查：

**确认条件**（先发生者优先，失效优先于确认）：
- 双顶：`low ≤ 颈线`（颈线 = 两顶之间的最低价）
- 双底：`high ≥ 颈线`（颈线 = 两底之间的最高价）

**失效条件**：
- 双顶：`high > max(top1_price, top2_price)`（涨过了两顶最高值，阻力已破）
- 双底：`low < min(bot1_price, bot2_price)`（跌破了两底最低值，支撑已破）

**超时**：超过 200 bar 未确认也未失效 → 自动放弃。

### 3.4 三重顶/底处理

若三个枢轴点价格接近（都在 2×ATR 范围内），则：
- 枢轴 1 + 枢轴 2 → 一个双顶/双底
- 枢轴 2 + 枢轴 3 → 另一个双顶/双底
- 枢轴 1 + 枢轴 3 → 不配对（因为枢轴 2 不可跳过）

## 四、标注方式

确认后永久标注，包含：
- 两个顶/底：小三角标签（双顶红色▼，双底绿色▲）
- 颈线：水平虚线，从第一个顶/底延伸至图表右边缘
- 形态名称：文字标签"双顶"/"双底"，置于颈线附近

## 五、规则速查

```
检测流程:
  新枢轴 → 推入队列(限5个) → 弹性搜索配对
    ├─ 价格偏差 ≤ 2×ATR ?
    ├─ 中间枢轴可跳过? (价格距离+形态边界)
    ├─ 中间回撤符合模式?
    └─ 进入待确认队列

  每 bar:
    待确认队列
      ├─ 超时(>200bar) → 放弃
      ├─ 失效(超出形态边界) → 放弃
      └─ 确认(颈线突破) → 永久标注
```

## 六、设计决策记录

| 决策 | 结论 | 依据 |
|------|------|------|
| 价格偏差用 ATR | 2×ATR，取第二个顶形成时的值 | 自适应波动，普适性更好 |
| 枢轴 lookback | 6 | 用户偏好短线 |
| 趋势过滤 | 不做 | 先做纯形态 |
| 目标位 | 不画 | 用户不需要 |
| 标注方式 | 永久保留 | 不因后续走势删除 |
| 毛刺边界 | 不能超出形态极值 | 用户补充——毛刺突破边界=形态不成立 |
