# 趋势线识别指标 — 逻辑说明

> 对应文件：`pine/趋势线识别.pine`
> 作用：在 K 线图上自动识别并画出上升/下降趋势线，所有历史趋势线保留。

---

## 一、整体思路

趋势线 = **一条线穿过 3 个枢轴点的影线**（三点共线）。识别流程：

```
新枢轴点 C 出现
  → 往前配一个中间点 B（前 N 个枢轴点逐个试）
    → 再往前找一个点 A（canAlign 判定 A、B、C 三点共线）
      → 通过层层约束 → 画线 [A → C]
```

下降趋势线连**高点**，上升趋势线连**低点**，逻辑完全对称。

---

## 二、参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `pivotLeft` | 10 | 枢轴点左侧看几根 K 线 |
| `pivotRight` | 10 | 枢轴点右侧看几根 K 线 |
| `maxPivots` | 50 | 保留多少个枢轴点（队列上限） |
| `pairCount` | 4 | 新点往前配几个「中间点 B」 |
| `maxSpan` | 400 | 相邻触点最大间隔 K 线数 |
| `showUpLines` / `showDnLines` | true | 是否显示上升/下降趋势线 |
| `upColor` / `dnColor` / `lineW` | — | 颜色和线宽 |

---

## 三、枢轴点检测

```pine
phPrice = ta.pivothigh(high, pivotLeft, pivotRight)   // 枢轴高点
plPrice = ta.pivotlow(low, pivotLeft, pivotRight)     // 枢轴低点
```

一根 K 线的高点比左右各 10 根都高，就是「枢轴高点」；低点同理。

---

## 四、枢轴点序列 + 影线范围

枢轴点**不是存一个价格，而是存一段影线区间**：

```
高点 → 上影线 [u, high]，u = max(open, close)   ← 实体上沿到最高价
低点 → 下影线 [low, l]，l = min(open, close)    ← 最低价到实体下沿
```

趋势线只要「穿过」这段影线（落在影线区间内），就算触到这个点。这就是「影线无极调节」的基础——连接点不必精确卡在最高价，可以在影线里滑动。

高点存 4 个数组：`phBar`（bar 位置）、`phTime`（时间戳）、`phHigh`（最高价）、`phU`（实体上沿）。低点对称存 `plBar`/`plTime`/`plLow`/`plL`。

---

## 五、三点共线判定（canAlign）

```pine
canAlign(barA, loA, hiA, barB, loB, hiB, barC, loC, hiC) =>
    k = (barA - barB) / (barC - barB)
    yA_lo = loB * (1 - k) + hiC * k
    yA_hi = hiB * (1 - k) + loC * k
    yA_lo <= hiA and yA_hi >= loA
```

**作用**：判断 A、B、C 三个影线区间能否被同一条直线穿过。

**数学含义**：
- 线由 B、C 两点确定，B 的连接点在 `[loB, hiB]` 内滑动、C 的连接点在 `[loC, hiC]` 内滑动。
- `k` 是 A 相对于 B、C 的位置系数（线性插值）。
- 线延伸到 A 处，可能的取值范围是 `[yA_lo, yA_hi]`。
  - `yA_lo`：B 取最低、C 取最高时，线在 A 处的值（最低）。
  - `yA_hi`：B 取最高、C 取最低时，线在 A 处的值（最高）。
- 如果这个范围 `[yA_lo, yA_hi]` 和 A 的影线 `[loA, hiA]` **有重叠**（`yA_lo <= hiA` 且 `yA_hi >= loA`），就存在一条线同时穿过 A、B、C 三个影线 → 三点共线。

> 高点传入 `u`/`high`（上影线），低点传入 `low`/`l`（下影线）。

---

## 六、影线无极调节（getLineHigh / getLineLow）

canAlign 只判断「**存不存在**」一条共线，getLineHigh 负责算出「**这条线具体画在哪**」（返回 A、C 两个端点的价格）。

```pine
getLineHigh(barA, uA, highA, barB, uB, highB, barC, uC, highC) =>
    t = (barB - barA) / (barC - barA)
    yA = highA
    yC = highC
    yB = yA * (1 - t) + yC * t
    if yB > highB
        yB := highB
        yA := (yB - yC * t) / (1 - t)
        if yA < uA
            yA := uA
            yC := (yB - yA * (1 - t)) / t
    [yA, yC]
```

**调节逻辑**（下降趋势线）：
1. 先让 A、C 都取影线**上沿**（`highA`、`highC`），算出 B 处的插值 `yB`。
2. 如果 `yB > highB`（线在 B 处太高，穿不过 B 的影线）：
   - 把 B 处降到 `highB`（影线上沿），反推 A 的新价格 `yA`。
   - 如果 `yA` 降过了 A 的影线下沿 `uA`，就把 A 固定在 `uA`，改降 C。
3. 最终返回 `[yA, yC]`——一条恰好穿过 A、B、C 三个影线的线。

**这就是「无极调节」**：连接点在影线里连续滑动（不设档位），找到能穿过所有点的精确位置。`getLineLow`（上升线）完全对称，只是从影线**下沿** `low` 开始、往相反方向调。

---

## 七、下降趋势线搜索流程（连高点）

当新的枢轴高点 C 出现时，执行以下步骤：

### 1. 记录新高点 C
存入 `phBar`/`phTime`/`phHigh`/`phU`，超上限 `maxPivots` 就 `shift` 掉最旧的。

### 2. 前 pairCount 个高点配 B
```pine
for bOff = 1 to pairCount        // 前 1~4 个高点依次当 B
    bIdx = cIdx - bOff
```

### 3. 检查下降方向 + 中间不突破
- `highC < highB`：B 必须高于 C（下降方向）。
- **midOk**：B 到 C 之间的枢轴高点，不能突破「B、C 取 high 的基准线」。

### 4. 往前扫描，找共线的 A
从 B 再往前（`aIdx = bIdx - 1` 递减）逐个取 A：
- `canAlign(A, B, C)` 通过 → 收集为候选 A（同时检查相邻触点间隔 ≤ `maxSpan`）。
- `canAlign` 不通过 → 检查 A 是否突破基准线（`highA > yBase` 就 `break`，因为更远的点只会更低，不必再扫）。

### 5. 从候选 A 里找「close 约束」通过的
从最远的候选 A 往近处逐个试：
- **okHigh**：A 必须是 A→B 之间的**最高**枢轴高点。
- `getLineHigh` 取可行解 `[yA, yC]`。
- `yA > yC`：确认是向下斜。
- **close 约束**：A 到 C 之间，每一根 K 线的**收盘价**都不能突破这条线。
- **触点间隔约束**：线穿过的触点，相邻间隔 ≤ `maxSpan`。

全部通过 → `line.new(timeA, yA, timeC, yC)` 画线，break（这条 B 只画一条）。

---

## 八、上升趋势线搜索流程（连低点）

与下降完全对称，只是：
- 连**低点**，影线是 `[low, l]`。
- 方向条件反过来：`lowC > lowB`（B 低于 C，上升方向）。
- 中间约束：枢轴低点不**跌破**线。
- `canAlign` / `getLineLow` 用下影线 `low`/`l`。
- close 约束：收盘价不**跌破**线。

---

## 九、约束清单汇总

| 约束 | 作用 | 位置 |
|------|------|------|
| 方向（`highC < highB` / `lowC > lowB`） | 保证趋势线方向正确 | 配 B 之后 |
| 中间不突破（midOk） | B→C 之间的毛刺不突破线 | 配 B 之后 |
| 三点共线（canAlign） | A、B、C 三个影线被一条线穿过 | 往前扫 A |
| 影线无极调节（getLineHigh/Low） | 算出线具体画在哪 | 取可行解 |
| A 是最高/最低点（okHigh/okLow） | A 须是 A→B 之间的极值 | 画线前 |
| close 约束 | A→C 收盘价不突破线 | 画线前 |
| 触点间隔（maxSpan） | 触点不隔太远 | 扫 A + 画线前 |

---

## 十、关键概念速记

- **枢轴点 = 影线区间**（不是单点价格），趋势线「穿过影线」即算触到。
- **三点共线（canAlign）** = 三个影线区间能被一条线穿过。
- **影线无极调节（getLineHigh/Low）** = 连接点在影线内滑动，算出精确的线。
- **一条趋势线 = 3 个触点（A、B、C）+ 价格不突破约束（midOk + close）**。
- **「3 点变 2 点」** = 去掉中间的 B 点（和 canAlign），A、C 直接连线。
